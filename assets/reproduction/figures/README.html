Reproducing the monograph’s figures

JoonHo Lee (jlee296@ua.edu)

The figure collection contains 40 numbered explanatory figures. Each of the 22 main chapters and five appendices has at least one. The collection includes conceptual maps, exact small examples, mathematical mechanisms and a bounded historical aggregate illustration. Their captions identify the relevant target, probability law, loss and feasible family; the figures do not establish empirical calibration or policy benefits.

Choose the reproduction target

There are 39 plotting entry points. Thirty-seven produce six files each: SVG, PDF and PNG in wide and separately composed mobile layouts. Two entry points produce only three mobile companion files for retained desktop originals. One original inclusion diagram is retained without a plotting entry point. The three retained original SVGs are identified by their bytes in manifest.json.

Replaying plots uses supplied small coordinates or literal symbolic labels. It does not refit a model, rerun KRW estimation, call an R package or optimize a report. Some producers check exact identities in the saved coordinates as part of plotting. Optional derivation programs and historical scientific archives have separate scopes and are not an implicit prerequisite to the selective commands below.

Preserve the directory layout

Run commands from a working root containing:

assets/
  reproduction/figures/
    figstyle.py
    data/
    generators/
    manifest.json
  figures/
    [the three retained original SVGs, when reproducing their slots]

Use the supplied assets/reproduction/figures tree in full: producers may import a shared panel from another generator directory. Do not flatten the folders. The shared style locates the working root from this structure. Source chapter names in provenance metadata identify controlling text; the plotting chain does not require private contracts, working logs, source PDFs, original empirical inputs or canonical QMD files.

The original SVGs can be copied from the rendered book’s assets/figures/ directory using the retained-asset entries in the manifest. They are preserved inputs, not outputs regenerated by Python. An isolated replay should keep its own working tree rather than overwrite the manuscript’s accepted assets.

Selective commands

Use an existing Python environment with the dependencies recorded in environment.json. The recorded authoring/replay environment is a description of the environment tested here. Installing an environment, using another platform or changing dependency versions is a separate operation; matching bytes on every platform is not promised.

For example, generate the analytical dependency map or the exact target-to-report illustration:

python -B assets/reproduction/figures/generators/F09c/generate.py
python -B assets/reproduction/figures/generators/F19a/generate.py

The mathematical proof-route figure imports its public route panel automatically:

python -B assets/reproduction/figures/generators/FA/generate.py

For the retained frontier’s mobile companion, or the retained reporting-versus-selection example’s mobile companion, use their actual distinct entry points:

python -B assets/reproduction/figures/generators/F16a/generate.py
python -B assets/reproduction/figures/generators/F19b-mobile/generate.py

manifest.json lists the command and expected outputs for every slot. F14a is a retained SVG and has no generation command. Do not interpret a staged panel driver or a coordinate-derivation helper as another final figure.

Use -B to avoid bytecode caches. Many producers refuse to overwrite outputs unless --overwrite is supplied; use that flag only for deliberate regeneration in your own working copy. Some early producers overwrite their named outputs directly. Keeping a separate replay tree is therefore the most reliable way to preserve accepted manuscript assets.

Check the outputs and display

The manifest records SHA-256 identities for the public sources, accepted plotting inputs and expected exports. Hash agreement identifies bytes. The distributed exports carry standardized author metadata; packaging metadata can change file hashes without changing plotted content. It does not prove the mathematics, validate the supplied probability law or certify an optimizer. A different environment can change rendering bytes without changing coordinates; inspect the declared quantities and actual images as well as file identities.

New SVG text is outlined as paths for font portability. PDF exports retain embedded fonts, and PNGs provide raster previews. Captions and alt text in the Quarto book supply the accessible descriptions. The retained original SVGs keep their original representation and declared export exceptions.

The book binds wide and mobile SVGs through responsive picture elements. Reproducing image files does not itself check the final caption, alt text, numbering, cross-reference, resource copying or mobile selection. A complete display check renders the book with scientific execution disabled and inspects both desktop and narrow contexts. Command records and visual checks are separate from the scientific plotting inputs.

Scientific and availability boundaries

Exact fixtures are stipulated illustrations under declared laws. The archived KRW figure uses accepted aggregate action summaries and does not rerun the original estimation. The weak-error theory and equality-neutral extension keep their separate events, denominators and feasible-family assumptions. Plotting a numerical error envelope does not turn it into an attained frontier or confidence guarantee.

This source collection is separate from the scientific example archive and from any package-source snapshot. Original figure sources are authored by JoonHo Lee (jlee296@ua.edu). Rights status is described in the repository’s RIGHTS.md.
