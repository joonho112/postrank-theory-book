Each complete two-unit domain vector has the same marginal law in both presets. For AB/AB, additive risk is 1/10 under both, but the joint error probability is 1/10 with coincident failures and 1/5 with disjoint failures. A state contributing errors in both domains is counted once in the union.

Two units; M = 1 in each domain; weak error includes target equality. Identity-only guards, no declared equality between distinct units, no mean caps. A zero objective weight does not remove protection. An all-withheld domain has N = 0, an undefined error fraction (NA), and a false exceedance event. The joint event uses strict F > tN; the cap is inclusive J ≤ alpha. Values are exact finite-law fractions.
