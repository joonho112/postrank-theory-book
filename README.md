# Decisions from Noisy Multidimensional Indicators

*Common Grades, Domain Profiles, and Posterior Decision Theory*

**JoonHo Lee ([jlee296@ua.edu](mailto:jlee296@ua.edu))** · [ORCID 0009-0006-4019-8703](https://orcid.org/0009-0006-4019-8703)

**Version v2.0.0** · [Zenodo DOI 10.5281/zenodo.24094442](https://doi.org/10.5281/zenodo.24094442) · [Read the online book](https://joonho112.github.io/postrank-theory-book/)

This Quarto book studies how to report comparisons when evidence is uncertain and several criteria matter. It develops common grades and domain profiles from a shared decision framework, then examines computation, evaluation, and applications in education and public policy. The [Preface](index.qmd) describes the book and suggests reading routes.

## How to cite this book

> Lee, J. (2026). *Decisions from noisy multidimensional indicators: Common grades, domain profiles, and posterior decision theory* (Version v2.0.0). Zenodo. <https://doi.org/10.5281/zenodo.24094442>

## Build the book

To build the HTML book, install Quarto and Python 3 and run `quarto render`. Open `_book/index.html` to read the result. The build uses the included figures, examples, and saved results.

See [CITATION.cff](CITATION.cff) for citation details and [RIGHTS.md](RIGHTS.md) for reuse information.
