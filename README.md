# Decisions from Noisy Multidimensional Indicators

*Theory, Evidence, and Posterior Grading*

**JoonHo Lee ([jlee296@ua.edu](mailto:jlee296@ua.edu))** · [ORCID 0009-0006-4019-8703](https://orcid.org/0009-0006-4019-8703)

A Quarto book on decisions from noisy multidimensional indicators: theory, evidence, and posterior grading.

## Build and preview

Requires [Quarto 1.9.37](https://quarto.org/docs/get-started/) and Python 3.

```sh
quarto render
quarto preview
```

The rendered book is `_book/index.html`. Reproduction materials are in [`assets/reproduction/`](assets/reproduction/); see Appendix E for instructions.

For citation and rights information, see [CITATION.cff](CITATION.cff), [RIGHTS.md](RIGHTS.md) and [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
